# VMECC Frontend

React/Vite frontend for the VMECC application.

## Requirements

- Node.js 22.23.1 LTS (see `.nvmrc`)
- npm

## Setup

```bash
npm install
cp .env.example .env
npm start
```

## Common Commands

```bash
npm start
npm run build
npm run serve
```

The production build is written to `build/`.
